## Работа с файлами и директориями

В Linux используются команды для перемещения, копирования и переименования файлов. Основные команды:

### Команды перемещения и переименования
- `mv <название файла | путь до файла> <название директории | путь до директории>`
  Переместить файл или директорию в выбранную директорию.
  *(Пример: `mv file.txt /home/user/documents`)*

- `mv <название файла | путь до файла> <путь до директории / новое имя файла>`
  Переименование файла или директории с возможным перемещением.
  *(Пример: `mv file.txt /home/user/documents/newfile.txt`)*

### Команды копирования
- `cp <название файла | путь до файла> <название директории | путь до директории>`
  Копировать файл в выбранную директорию.
  *(Пример: `cp file.txt /home/user/backup/`)*

- `cp -r <название директории | путь до директории> <название директории | путь до директории>`
  Копировать директорию с ее содержимым.
  *(Пример: `cp -r /home/user/source /home/user/destination`)*

## Работа с текстовым редактором Vim

**Vim** — это мощный текстовый редактор, широко используемый в Linux для редактирования файлов. Основные команды:

- `vim <название файла | путь до файла>`
  Открыть файл в редакторе vim.
  *(Пример: `vim script.sh`)*

### Основные режимы и команды в Vim:
1. **Режим редактирования**: Нажмите `i`, чтобы начать редактирование файла.
2. **Режим командной строки**: Нажмите `:` для ввода команд.
3. **Выход в режим просмотра**: Нажмите `Esc`.

### Полезные команды:
- `:wq` — сохранить изменения и выйти.
- `:q` — выйти из файла (если нет изменений).
- `:saveas <название файла>` — сохранить файл с новым именем.

## Пользователи и права

Linux — это многопользовательская система, где каждый пользователь имеет свой набор прав и привилегий. Основные команды для работы с пользователями:

- `sudo useradd -m <имя пользователя>`
  Создать нового пользователя и его домашнюю директорию.
  *(Пример: `sudo useradd -m dmitrii`)*

- `passwd <имя пользователя>`
  Задать пароль для пользователя.
  *(Пример: `passwd dmitrii`)*

- `su <имя пользователя>`
  Переключиться на другого пользователя.
  *(Пример: `su dmitrii`)*

- `sudo usermod -aG wheel <имя пользователя>`
  Добавить пользователя в группу с особыми правами (например, `wheel`).

## Подключение к удаленным серверам

Для удаленного управления серверами используется команда `ssh` (Secure Shell).
Пример подключения:
```bash
ssh <имя_юзера>@<адрес_сервера>
ssh dmitrii@192.168.0.1
```

## Работа с процессами и системными ресурсами

Процессы — это программы, выполняющиеся в системе. Для управления ими используются следующие команды:

- `htop`
  Просмотр списка запущенных процессов в удобном интерфейсе.

- `kill <PID>`
  Завершить процесс с указанным идентификатором (PID).
  *(Пример: `kill 1234`)*

## Отличия суперпользователя от обычного

**Суперпользователь** имеет полный контроль над системой:
- Доступ к системным и конфигурационным файлам.
- Управление пользователями и группами.
- Возможность выполнять любые команды без ограничений.

**Обычный пользователь**:
- Ограничен в доступе к системным файлам.
- Не может изменять конфигурации системы без команды `sudo`.
- Может выполнять команды только в рамках своего пространства.

Использование **sudo** позволяет временно выполнять команды с правами суперпользователя. Например обновить пакетный менеджер:
```bash
sudo apt update
```
