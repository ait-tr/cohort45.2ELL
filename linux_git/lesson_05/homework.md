# Работа с пользователями и файлами в Linux


Для выполнения задания можно использовать эмулятор Linux:
[Эмулятор Linux для работы](https://bellard.org/jslinux/vm.html?cpu=riscv64&url=fedora33-riscv.cfg&mem=256)

---

## Задание

1. Создайте пользователя **aragorn**, задайте ему пароль. Создайте в корне файл **aragorn.json** через редактор **vim** по образцу:
   ```json
   {"user": "aragorn", "pass": "ваш_пароль", "isSuper": false}
   ```

2. Создайте пользователя **gendalf**, задайте ему пароль. Сделайте его суперпользователем. Создайте в корне файл **gendalf.json** через редактор **vim** по образцу:
   ```json
   {"user": "gendalf", "pass": "ваш_пароль", "isSuper": true}
   ```

3. Создайте в корневой директории папку **hints**. Скопируйте в нее файлы **aragorn.json** и **gendalf.json**.

4. Авторизируйтесь под обоими пользователями (**aragorn** и **gendalf**), затем вернитесь в сессию суперпользователя или корневого пользователя.
