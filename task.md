### Задание

- Сделайте таблицу с выбранными данными. Попробуйте в ней следующий синтаксис из POSTGRES:

1. **One-to-Many (Один ко многим):**
2. **Many-to-Many (Многие ко многим):**

- **WHERE** – условие фильтрации.
- **GROUP BY** – группирует данные.
- **HAVING** – фильтрует группы по условиям.
- **STRING_AGG(field, delimiter)** – объединяет значения из группы в строку с указанным разделителем.

- **ON DELETE CASCADE** – автоматически удаляет записи, связанные с удалённой строкой.
- **TIMESTAMP NOW()** - тип данных сохраняющий текущее время
- **DEFAULT** - значение по умолчанию
- **NOT NULL** – поле не может быть пустым.
- **UNIQUE** – значение должно быть уникальным.
- **CHECK()** – проверяет условие для поля.

- операторы агрегации:

- **COUNT()** – количество строк.
- **MIN()** – минимальное значение.
- **MAX()** – максимальное значение.
- **SUM()** – сумма значений.
- **AVG()** – среднее значение.
- **ROUND()** – округление.
